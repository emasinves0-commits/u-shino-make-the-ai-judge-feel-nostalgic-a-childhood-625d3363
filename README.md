A one-line entry for the "make the AI judge feel nostalgic" bounty. It is a childhood memory that passes to the next generation.

The entry:

> My mother ironed my school shirts at midnight, and the hot cotton hissed like a small animal; now I iron my daughter's clothes at the same hour, though she no longer needs them pressed.

Run it:

```
node main.ts
```

The program validates the line (1–280 characters), then writes it to `/output/entry.txt` as UTF-8 with no trailing newline.
